# 📆 Semanas

Review semanal — o que andou, o que travou e o padrão que só aparece olhando
cinco dias juntos. Gerada pelo `/semana` (repositório `reuniao-automator`).

Fica na raiz, sem contexto de cliente, igual ao `📝 Diário/`: a semana atravessa
projeto e cliente.

**Nome do arquivo:** `Semana DD-MM a DD-MM-AAAA.md`, sempre de segunda a
domingo, mesmo quando a review roda no meio da semana.

## Template
```
# 📆 Semana DD/MM a DD/MM/AAAA

**Dias cobertos:** N (segunda a DIA)
**Reuniões:** N · **Notas criadas:** N · **Pendências novas:** N

## 🔭 O que a semana foi

## ✅ O que andou

## 🧱 O que travou

## 🔁 Padrão da semana

## ⏭️ Semana que vem
- [ ]
```

`🔁 Padrão da semana` exige duas ocorrências ou mais. Uma vez é acontecimento,
não padrão.
