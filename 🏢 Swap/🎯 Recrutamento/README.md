# 🎯 Recrutamento

Vagas abertas, candidatos e comparativos. Fica **fora** de `👥 Time/` de
propósito: o `vault.py --pessoas` trata como pessoa qualquer nota sob uma pasta
que termine em "Time", então candidato ali dentro apareceria como se fosse do
time e poderia virar `[[link]]` numa nota de reunião.

Quando a vaga fecha: o contratado ganha nota em `👥 Time/`, e as notas dos
candidatos vão para `🗃️ Arquivo/`.
