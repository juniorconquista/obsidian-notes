# 🤝 Interfaces

Pessoas de fora do time direto com quem o trabalho acontece — lideranças de
outras áreas, pares, contrapartes. Elas entram nas notas de reunião como
`[[link]]` igual a qualquer pessoa, e por isso a pasta fica **dentro** de
`👥 Time/`: o `vault.py --pessoas` varre tudo sob "Time", então o link continua
resolvendo.

A separação é só para a lista de `👥 Time/` mostrar quem é do time direto.

Usa o mesmo template de Nota de Pessoa do `CLAUDE.md`, com `**Área:**` apontando
a área de origem.
